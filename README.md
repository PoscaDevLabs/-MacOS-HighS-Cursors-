# CURSORS
These cursors are made to replicate the MacOS High Sierra - MacOS Sequoia Cursors. Everything from the colours to the animations are the same.





# NOTE
NONE of these cursors are mine, in fact they're Apple Incorporated's all made into .cur and .ani files by Antiden on Github (https://github.com/antiden/macOS-cursors-for-Windows)





# AFFILIATES NOTE
I am not partnered or affiliated with Antiden or Apple Incorporated as Antiden packages MacOS cursors as .cur and .ani files and i just packaged them into a .bat file that sets up the cursor
