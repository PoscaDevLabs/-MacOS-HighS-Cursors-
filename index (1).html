ABOUT THE PROJECT

Inspired by an
iconic interface.

This project aims to make a Windows cursor setup feel closer to the classic macOS High Sierra look, with cursor styles inspired by the macOS era from High Sierra through Sequoia.

The cursor artwork is credited to Antiden. PoscaDevLabs packages the cursor setup and provides this project page.
